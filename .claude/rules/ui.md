# Page layout

- Informational text stays out of the page. A card shows its fields and
  actions; explanations, notes and status messages go behind an icon that
  opens a modal: an (i) for information, a red ! for something that needs
  attention (e.g. an unconfirmed address), whose modal holds the action as
  a button. The profile's e-mail field and "Personal information" (i) are
  the pattern.
