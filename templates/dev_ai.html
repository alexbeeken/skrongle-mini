The dev AI provider

A stand-in for Anthropic and OpenAI (and Gemini's OpenAI endpoint) that speaks their real APIs and answers from the fixtures. Mode: {{ mode }}.

Base URLs:

    {% for b in bases %}
  • {{ b.0 }}: {{ b.1 }}
    • {% endfor %}

The learner's own keys profile is the keys on a learner's profile, with its usage, limit and injected failure. Once over the limit, Anthropic answers HTTP 400 "You have reached your specified API usage limits", OpenAI HTTP 429 insufficient_quota. Dollars come from a made-up price table (per million tokens; tokens are 4 characters). The app's client gives up after {{ timeout }}.

In memory until the server stops. As JSON: state, log and fixtures.

Manual replies

On, each request the fixtures would answer is written to the capture directory (SKRONGLE_LLM_DIR, ./dev-llm) and waits in the Manual replies section at the bottom of this page until you answer it there (or write its .response.txt). A reply starting with ERROR: answers with that error. Usage limits and injected failures still come first.

./.dev-start --llm capture starts with it on.

Fixtures

One file per call site (generate-outline, tutor-turn, …), with replies by key: a lesson's slug, else a [fixture:NAME] token in the prompt (e.g. in the wish), else default; then *. The app names the call site in its x-skrongle-call header.

Edits are in memory for this server run. Save to file writes them back; Reset goes back to the file.
