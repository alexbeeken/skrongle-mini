The dev authenticator

An authenticator app (like Google Authenticator) for two-factor sign-in. Paste an otpauth://totp/… link or a setup key, or open a link to /dev/authenticator?uri=otpauth://… (the "scan"). Each account shows its current code (RFC 6238 TOTP, worked out from its secret) and when it changes.

Kept in memory until the server stops. As JSON: accounts and codes.
