Background jobs

The newest rows of the jobs table. The runner thread takes a row when it is due, leases it for 10 minutes and runs it. A failed run goes back in the queue for a later try, until its attempts run out. Each housekeeping job queues its next run an hour after it ends.

Run now makes a queued row due now, or ends a running row's lease as if its server had stopped. Queue a failing job adds one that always fails, to watch the retries.
