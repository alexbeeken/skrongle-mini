About the dev test client

A public OAuth client, as an app in a vendor's cloud is: it reads the discovery documents, registers itself, asks for access with PKCE, trades the code for tokens and calls /api/v1/whoami. Its state lives in this tab. Needs SKRONGLE_PUBLIC_URL and Let apps connect.

Using the old refresh token or replaying the code is refused and disconnects the app: whoami then answers 401, and Connect starts again.
